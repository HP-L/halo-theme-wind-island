## 前言

选择一个博客主题只是开始，真正让博客「属于你」的，是那些个性化的调整。这篇文章将以风屿主题为例，带你一步步打造一个与众不同的个人博客。

## 第一步：确定博客定位

在动手之前，先想清楚你的博客定位：

- **个人技术博客**：需要代码高亮、清晰的分类体系、简洁的阅读体验
- **摄影/设计作品集**：注重视觉呈现、大图展示、留白和排版
- **生活随笔**：温暖亲切的色调、轻松自然的排版

不同的定位会影响后续的配色选择和首页布局。

## 第二步：选择配色

风屿的四套配色各有所长。我的建议是：

- 技术博客 → 夜屿（深色专业感）
- 生活随笔 → 暮屿（温暖亲切）
- 设计作品 → 晓屿（素净留白）
- 通用站点 → 随境（自适应）

你可以在 `_config.wind-island.yml` 中设定：

```yaml
style:
  color_scheme: nightIsland
```

## 第三步：设置首页

首页是博客的门面。风屿提供了丰富的首页布局选项。

### 添加主视觉图

```yaml
home:
  hero_image: "/images/my-hero.jpg"
```

选一张能代表你博客调性的图片。摄影作品、插画、或者简洁的几何图形都是不错的选择。

### 展示精选内容

如果你有一些特别想让读者看到的文章，可以在文章的 front-matter 中添加 `pinned: true`，然后配置：

```yaml
home:
  cover_strip_source: pinned
```

这些文章会在首页以醒目的卡片形式展示。

### 配置专题集合

如果你写了系列文章，可以按分类组织成专题：

```yaml
home:
  topic_categories:
    - 教程
    - 实践
    - 进阶
```

## 第四步：完善导航

合理的导航结构让访问者能快速找到想要的内容：

```yaml
menu:
  首页: /
  归档: /archives
  分类: /categories
  标签: /tags
  友链: /links
  关于: /about
```

如果你有独立页面（如「关于我」），用 `hexo new page about` 创建后，在菜单中加上对应路径即可。

## 第五步：页脚备案信息

如果你在中国大陆运营网站，需要配置备案信息：

```yaml
footer:
  copyright_start_year: "2026"
  icp_number: "京ICP备XXXXXXXX号"
  icp_url: "https://beian.miit.gov.cn/"
```

## 第六步：文章写作技巧

### 使用 Tag 插件

风屿兼容 Hexo 的标准标签插件，在文章中使用可以增强内容表现力：

```markdown
{% note info %}
这是一条提示信息
{% endnote %}
```

### 启用阅读设置

让读者有更好的阅读体验：

```yaml
post:
  enable_reader_settings: true
  reading_time: true
```

### 设置文章封面

在 front-matter 中添加封面图，让文章在列表和卡片中更加醒目：

```yaml
---
title: 我的文章
cover: /images/post-cover.jpg
---
```

## 总结

风屿主题的设计哲学是「开箱即美，按需可调」。你不需要修改一行主题源码，仅通过配置文件就能完成大部分个性化需求。当你想更进一步时，主题的 CSS 变量体系和模块化结构也为深度定制留出了空间。

希望这篇指南能帮助你打造出一个真正属于自己的博客空间。如果你有任何问题或改进建议，欢迎在 GitHub 上提出。

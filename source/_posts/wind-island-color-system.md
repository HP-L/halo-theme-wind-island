## 概述

风屿主题的颜色系统被称为「风屿色」（Island Color），是整套主题视觉语言的核心。四套配色方案分别对应不同的时间和氛围，让博客在不同场景下展现出独特的个性。

## 四套配色方案

### 夜屿（nightIsland）

夜屿是风屿的默认配色，也是原始品牌色。

**设计理念**：模拟深夜岛屿的氛围。深蓝黑色背景搭配柔和暖色点缀，降低屏幕蓝光刺激，适合长时间阅读。

**特点**：
- 深色背景，减少眼部疲劳
- 高对比度但不过于刺眼
- 暖色调的链接和强调色，在黑暗中温暖但不喧闹

**适用场景**：夜间阅读、编程博客、技术文档

### 晓屿（dawnIsland）

**设计理念**：清晨天刚亮时的岛屿——白纸与墨色，素净清冷。

**特点**：
- 纯白背景，极简风格
- 银灰色文字，类似纸质书阅读感
- 淡雅的强调色点缀

**适用场景**：文学博客、个人日记、设计作品集

### 暮屿（duskIsland）

**设计理念**：黄昏时分的 Blue Hour 与余晖。天色介于蓝紫之间，夕阳在地平线留下最后一道暖光。

**特点**：
- 暖色调背景，如同黄昏的光线
- 蓝紫色与橙色的互补搭配
- 温馨而沉静的阅读氛围

**适用场景**：摄影博客、旅行记录、生活方式分享

### 随境（followSystem）

**设计理念**：不固定配色，自动跟随访客设备的系统明暗模式。

**特点**：
- 系统亮色模式时自动切换浅色方案
- 系统暗色模式时自动切换深色方案
- 只需设置一次，体验最自然

**适用场景**：面向广泛读者的博客、企业站点

## 如何修改配色

### 全局默认配色

在 `_config.wind-island.yml` 中设置：

```yaml
style:
  color_scheme: duskIsland
```

所有访客首次访问时将看到你设定的默认配色。

### 访客前端切换

风屿提供了前端配色切换器。访客点击导航栏的配色按钮，可以在四套方案中自由选择。选择结果保存在 `localStorage` 中，下次访问时自动恢复。

### 配色之间的关系

四套配色并非完全独立。它们共享相同的 CSS 变量体系，只是变量值不同：

| CSS 变量 | 夜屿 | 晓屿 | 暮屿 |
|----------|------|------|------|
| 背景色 | 深蓝黑 | 纯白 | 暖灰 |
| 正文色 | 浅灰白 | 银灰 | 深棕 |
| 强调色 | 暖金 | 淡蓝 | 橙棕 |
| 链接色 | 柔和蓝 | 深蓝 | 暖橙 |

这种 CSS 变量体系使得配色切换可以瞬间完成，无需重新加载页面。

## 自定义配色

如果你想创建自己的配色方案，可以覆盖主题的 CSS 变量。在 `source/css/custom.css` 中添加：

```css
:root[data-color-scheme="myCustom"] {
  --color-bg-primary: #你的背景色;
  --color-text-primary: #你的正文色;
  --color-accent: #你的强调色;
  --color-link: #你的链接色;
}
```

然后在主题代码中注册新的配色名称即可。

## 配色与无障碍

风屿的所有配色方案都经过了 WCAG 2.1 AA 级别的对比度验证，确保：

- 正文与背景的对比度 ≥ 4.5:1（AA 标准）
- 大号文字与背景的对比度 ≥ 3:1
- 链接文字与周围正文有明显区分（不仅依赖颜色）

这确保了色觉障碍用户和低视力用户也能获得良好的阅读体验。
